# Breast Cancer PCA Explorer

This project explores the Breast Cancer Wisconsin dataset using correlation analysis and Principal Component Analysis (PCA).

The Streamlit application includes:
- A preview of the dataset
- A correlation heatmap
- A two-dimensional PCA projection
- An option to color PCA points by diagnosis or mean radius group
- PCA loadings
- Identification of the top variables contributing to PC1 and PC2
- A brief interpretation of the PCA results
